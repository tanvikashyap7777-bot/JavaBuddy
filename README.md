# JavaBuddy

JavaBuddy is a simple Java learning app that helps students practice coding, run Java programs, and get help when something goes wrong.

## What this project does

- Write Java code in the browser
- Compile and run the code on the server
- View output and compiler errors
- Ask an AI tutor for explanations and fixes
- Learn Java through a guided coding experience

## Features

- Interactive Java compiler
- Error diagnosis and suggestions
- AI-powered Java mentor
- Fast frontend built with React
- Express backend for code execution APIs

## Tech stack

- React + Vite
- TypeScript
- Express
- Gemini AI API
- Capacitor (for app packaging)

## Getting started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the app in development mode:
   ```bash
   npm run dev
   ```

3. Open your browser at:
   ```bash
   http://localhost:3000
   ```
